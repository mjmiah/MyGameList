# MyGameList
A web app to store and score the video games you have played.
<img width="2559" height="1281" alt="image" src="https://github.com/user-attachments/assets/b1e66467-c9f3-47de-a602-a1f7051ae6d3" />
Watch the demo:

[![MyGameList Demo](https://img.youtube.com/vi/Yur6Ww7IdNg/0.jpg)](https://www.youtube.com/watch?v=Yur6Ww7IdNg)

For the backend, I wrote an API in .NET to handle an SQL database using Entity Framework, and fetching video game data from the IGDB API. Then React for the frontend.
I have been testing the API using Scalar.
